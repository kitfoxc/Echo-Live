随机消息 JSON 编辑器

使用 Echo-Live 原生消息结构编辑预设。不再将快速格式化代码当作数据；消息中的 text、style、data、pause、typewrite 等字段以 JSON 形式保存。

消息列表 (0)

每个编号代表一个随机预设。预设可以是一条消息，也可以是按顺序发送的消息队列。

消息源码

编辑当前预设的完整 JSON 值。可使用字符串、段落对象、段落对象数组，或带 messages 数组的队列对象。应用时会验证 JSON 语法。

结构示例
单条富文本：{"text":"欢迎","style":{"bold":true,"color":"#66CCFF"}}
多文本段落：[{"text":"第一段","style":{"bold":true}},{"text":"第二段","pause":8}]
消息队列：{"name":"欢迎队列","messages":[{"message":"第一条"},{"message":[{"text":"第二条","style":{"italic":true}}]}]}
原生段落字段可包含 class、style、data、typewrite、ruby、pause、speed、event 等。队列中每项使用 Echo-Live 消息信封 {"message": ...}。
模拟播放预览

预览会呈现常见文本和样式；打印动画、扩展样式类、表情资源及自定义事件需要在实际 Echo-Live 环境中验证。原生字段会保留在源码中，即使预览无法完全模拟。
